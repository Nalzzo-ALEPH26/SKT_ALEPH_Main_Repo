# 눈치오목 v2 · BETA 05

> **생각은 몰래, 승부는 동시에.**
> 6개의 돌로 연결과 견제를 함께 계획하고, 좁아지는 판에서 정확히 5개를 연결하는 2~6인 웹 보드게임입니다.

[게임 실행](https://nunchi-omok.nalzzoaleph26.workers.dev/) · [GitHub 소스](https://github.com/Nalzzo-ALEPH26/SKT_ALEPH_Main_Repo/tree/main/nunchi-omok)

## 이번 업데이트

- 생존 돌이 있으면 **총 6개 배치**, 기존 위치 **최소 2개 유지** (1개만 생존하면 그 1개 유지).
- 선택 시간 **25초**. 모두 제출하면 바로 공개.
- **4라운드부터 짝수 라운드마다 외곽 한 줄 영구 폐쇄**.
- 경기 종료 후 **다시 보기**: 재생·일시정지·라운드 이동·1/2/4배속.
- 정확히 5개 연결만 승리. 6개 이상 연속된 줄은 승리로 인정하지 않음.

## 시작 방법

1. 닉네임을 입력하고 방을 만듭니다.
2. 친구에게 게임 링크와 6자리 방 코드를 공유합니다.
3. 2명 이상 모두 준비를 완료하면 방장이 시작합니다.
4. 제한 시간 동안 위치를 선택하고 배치 완료를 누릅니다.
5. 경기 종료 후 다시 보기를 열거나 방장이 다시 한 판을 선택합니다.

진행 중 입장한 사람은 관전하고 다음 경기에 참여합니다. 최대 방 인원은 관전자를 포함해 6명입니다.

## 배치와 승리

| 상황 | 최종 선택 개수 |
|---|---:|
| 첫 라운드 | 3개 |
| 충돌·폭격으로 전멸한 다음 라운드 | 3개 |
| 기존 생존 돌이 있는 라운드 | 6개 |

생존 돌이 2개 이상이면 그중 최소 2개는 기존 위치를 유지합니다. 유지할 돌은 매 라운드 본인이 선택합니다. 생존 돌이 1개뿐이면 그 1개를 유지합니다.

| 이전 생존 돌 | 최소 유지 개수 | 최종 배치 | 새롭게 정할 위치 |
|---|---:|---:|---:|
| 0개·첫 라운드 | 0개 | 3개 | 최대 3개 |
| 1개 | 1개 | 6개 | 최대 5개 |
| 2개 이상 | 2개 | 6개 | 최대 4개 |

3개를 유지하면 최대 3개, 4개를 유지하면 최대 2개 위치를 새롭게 정할 수 있습니다. 돌을 매번 추가하는 방식이 아니라 최종 배치 전체를 다시 선택하는 방식입니다.

같은 칸에 여러 플레이어가 배치하면 해당 칸의 돌은 모두 제거됩니다. 상대의 이전 위치를 선택해도 상대가 옮겼다면 충돌하지 않습니다. 고정한 돌도 충돌·폭격·폐쇄로 사라집니다.

승리 판정은 **충돌 → 폭격·폐쇄 → 정확히 5목** 순서입니다.

- 가로·세로·대각선 중 한 방향으로 정확히 5개가 이어지면 승리합니다.
- 여섯 번째 돌이 다른 곳에 있다면 5목 승리를 방해하지 않습니다.
- 한 줄로 6개가 이어지면 그 줄로는 승리하지 못합니다.
- 6개 줄의 끝 돌이 폭격으로 제거되어 최종 5개가 남으면 승리할 수 있습니다.
- 같은 라운드에 여러 명이 완성하면 공동 우승입니다.

배치 완료는 필요한 돌을 모두 선택했을 때 가능합니다. 시간이 끝나면 서버에 저장된 유효한 배치로 처리하므로 일부만 선택한 상태도 공개될 수 있습니다. 선택 위치는 공개 전까지 본인에게만 보입니다.

## 보드와 활동 영역

| 시작 인원 | 보드 크기 | 최소 활동 영역 |
|---|---:|---:|
| 2~3명 | 7×7 | 5×5 |
| 4명 | 8×8 | 6×6 |
| 5~6명 | 9×9 | 7×7 |

대기실에서 예정 보드 크기를 확인할 수 있습니다. 실제 크기와 최소 영역은 시작 인원으로 확정하며, 경기 중 퇴장·관전 입장으로 바뀌지 않습니다. 다음 경기는 새 인원으로 다시 결정합니다.

외곽 폐쇄는 현재 사용 가능한 직사각형 영역의 위·아래·왼쪽·오른쪽 한 줄을 없앱니다. 하한보다 작은 방향으로는 더 줄이지 않습니다. 보드와 A~I / 1~9 좌표는 그대로 유지하고 폐쇄한 칸만 어둡게 표시합니다.

## 폭격과 폐쇄

| 라운드 | 효과 |
|---|---|
| 1 | 없음 |
| 2~3 | 무작위 폭격 |
| 4부터 짝수 라운드 | 축소 여지가 있으면 외곽 한 줄 영구 폐쇄 |
| 그 외 | 무작위 폭격 |
| 최소 활동 영역에 도달한 후 | 칸 폭격만 진행 |

일반 폭격은 칸 50%, 가로줄 25%, 세로줄 25%로 종류를 고른 후 사용 가능한 위치를 정합니다. 이미 영구 폐쇄된 칸은 대상에서 제외하고, 이전 잿더미와 완전히 겹치는 폭격은 피합니다. 외곽 폐쇄는 축소 가능한 방향 중 무작위로 선택합니다.

선택 시간이 시작될 때 서버가 대상 위치를 확정해 모두에게 예고합니다. 위험 지역에도 돌을 둘 수 있지만 공개 후 제거됩니다. 영구 폐쇄 라운드에는 일반 폭격을 추가하지 않습니다.

| 표시 | 의미 | 배치 |
|---|---|---|
| 주황색·느낌표 | 이번 폭격 또는 폐쇄 예정 | 가능, 공개 후 제거 |
| 빗금·▧ | 직전 일반 폭격의 잿더미 | 이번 라운드 불가 |
| 어두운 칸·▣ | 영구 폐쇄 | 경기 종료까지 불가 |

일반 폭격의 잿더미는 다음 선택 라운드 한 번만 유지합니다. 예를 들어 2라운드 폭격 위치는 3라운드에 금지되고 4라운드에 해제됩니다. 영구 폐쇄는 해제되지 않습니다.

## 시간과 종료

선택은 25초, 공개 연출은 별도 2초입니다. 남은 10초와 5초에 타이머와 안내를 강조합니다. 모든 참가자가 제출하면 일찍 공개합니다. 움직임 줄이기 설정에서는 기존 폭탄 낙하·섬광을 생략합니다.

최대 라운드와 전체 시간 제한은 없습니다. 약 3분은 목표이며 보장 시간이 아닙니다. 외곽 폐쇄가 반복 견제를 줄이더라도 경기 종료를 반드시 보장하지는 않습니다.

## 경기 다시 보기

경기 종료 후 화면 아래의 **최근 경기 다시 보기**를 누릅니다. 다시 보기 안에서 재생을 누르면 아래 네 장면을 반복합니다.

1. 이전 생존 돌과 위험 지역
2. 최종 제출 배치 동시 공개
3. 충돌 처리
4. 폭격·폐쇄 이후 결과와 승리 연결 강조

재생·일시정지, 이전·다음 라운드, 라운드 슬라이더, 1/2/4배속을 지원합니다. 재생은 각자 화면에서 진행되며 다른 사람의 재생이나 방 상태를 변경하지 않습니다. 다음 경기는 별도로 진행되므로 플레이할 때 다시 보기를 닫아주세요.

방마다 가장 최근에 끝난 경기 기록을 제공하며, 다음 경기가 끝나면 더 오래된 기록은 정리합니다. 진행 중 경기 기록은 공개하지 않습니다. 방을 나가면 다시 보기 접근 권한도 없어집니다. 공개된 라운드 없이 기권으로 끝난 경기는 빈 기록 안내를 표시합니다. 업데이트 이전 경기는 소급해서 재생할 수 없습니다.

## 업데이트 적용 및 저장 구조

진행 중인 이전 경기는 해당 경기의 기존 규칙을 유지합니다. BETA 04 경기는 최소 1개 유지·총 6개·25초로 마무리됩니다. 새 방에서 시작하거나 기존 경기를 끝내고 다시 시작하면 BETA 05가 적용됩니다. 모든 참가자는 업데이트 후 강력 새로고침을 해주세요.

기존 `DB` 바인딩을 사용하며, 첫 새 경기 시작 시 `game_replays` 테이블과 방 검색 인덱스를 자동 생성합니다. 기존 테이블 삭제, DB 초기화, 새 바인딩은 필요 없습니다.

라운드별 기록은 방의 현재 상태와 분리해 저장하고, 종료 후에만 인증된 방 참가자가 100라운드씩 읽습니다. 화면에서는 한 번 받은 기록으로 재생해 배속 변경·라운드 이동마다 서버 요청을 보내지 않습니다. 방 상태 변경과 라운드 기록 저장은 하나의 트랜잭션으로 처리합니다. 구현에 사용한 API 동작은 [Cloudflare D1 batch 문서](https://developers.cloudflare.com/d1/worker-api/d1-database/#batch)를 참고하세요.

## 검증

의존성 설치 후 게임 폴더에서 실행합니다(Node.js 22.13 이상).

```sh
node tests/rules.mjs
node tests/bombs.mjs
node tests/board-size.mjs
node tests/optimistic.mjs
node tests/evolution.mjs
node tests/two-anchors.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
node node_modules/vinext/dist/cli.js build
```

정확한 5목과 6목 거부, 6개 배치와 기존 돌 유지, 25초, 2~6명 폐쇄 하한, 전멸, 기록 순서·개인정보 제외, 기록 실패 롤백, 동시 제출, 중복 기록 방지, 인증, 페이지 나눔, 재경기를 테스트합니다.

실제 사용자 간 밸런스는 배포 후 2·4·6인으로 확인합니다. 경기 시간, 종료 라운드, 시간 초과, 전멸 횟수와 외곽 승리 비율을 기록해 폐쇄 속도를 조정합니다.
