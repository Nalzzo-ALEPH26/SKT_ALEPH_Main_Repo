## 프로젝트 소개

눈치오목은 일반 오목처럼 돌을 한 개씩 계속 추가하는 게임이 아닙니다.

모든 플레이어가 제한 시간 동안 자신의 돌 위치를 **비공개로 선택**하고, 선택이 끝나면 모든 배치를 동시에 공개합니다.

같은 위치를 두 명 이상이 선택하면 해당 위치의 돌은 모두 제거되며, 충돌 처리 후 자신의 돌 5개가 가로·세로·대각선 중 한 방향으로 이어지면 승리합니다.

v2에서는 매 라운드 모든 돌을 완전히 새로운 위치로 옮길 수 있었던 초기 규칙을 수정하여, **기존에 살아남은 돌이 있다면 최소 1개는 반드시 유지**하도록 했습니다.

| 항목 | 내용 |

# 게임 시작 방법

1. 닉네임을 입력합니다.
2. **새로운 방 만들기**를 선택합니다.
3. 생성된 **6자리 방 코드**와 게임 링크를 친구에게 공유합니다.
4. 다른 플레이어는 닉네임과 방 코드를 입력하여 참가합니다.
5. 2명 이상이 모이면 참가자들이 **준비 완료**를 선택합니다.
6. 방장이 **게임 시작**을 선택합니다.
7. 승자가 결정될 때까지 라운드를 반복합니다.
8. 게임 종료 후 방장이 **다시 한 판**을 선택하면 다시 대기실로 이동합니다.

경기가 이미 진행 중일 때 참가한 사용자는 다음 경기를 기다립니다.

# 게임 규칙

## 1. 보드 크기

게임 시작 시 참가 인원에 따라 보드 크기가 결정됩니다.

| 참여 인원 | 보드 크기 |
|---|---:|
| 2~3명 | 7×7 |
| 4명 | 8×8 |
| 5~6명 | 9×9 |

보드 크기는 돌을 놓을 수 있는 교차점의 수를 의미합니다.

대기실에는 현재 참가 인원과 예정 보드 크기, 격자 미리보기가 표시됩니다. 입장·퇴장 시 자동 갱신하며, 1명일 때는 2명 이상 필요하다는 안내를 표시합니다.

실제 보드 크기는 게임 시작 시 서버가 확정합니다. 한 번 경기가 시작되면 퇴장·관전 참가·재접속이 발생해도 크기는 변경되지 않습니다. 다시 한 판을 시작하면 새로운 참가 인원에 맞춰 다시 결정합니다.

게임 보드에는 열 문자(A~I)와 행 숫자(1~9)를 크기에 맞춰 표시합니다.

각 플레이어는 서로 다른 색상과 표식으로 구분됩니다.

---

## 2. 첫 라운드

첫 라운드에서는 모든 플레이어가 **돌 3개**를 선택합니다.

첫 라운드에는 돌이 3개뿐이므로 승리할 수 없습니다.

15초 동안 원하는 위치를 선택한 뒤 제출합니다.

모든 플레이어가 먼저 제출하면 시간이 남아 있어도 바로 공개 단계로 진행합니다.

---

## 3. 두 번째 라운드 이후

기존에 살아남은 돌이 있다면 기존 돌과 새롭게 선택한 돌을 합쳐 **최종 5개 위치**를 정합니다.

단, 기존 생존 돌 가운데 **최소 1개는 이전 위치에 유지해야 합니다.**

| 기존 돌 유지 | 새롭게 정할 수 있는 위치 | 최종 돌 수 |
|---:|---:|---:|
| 1개 | 최대 4개 | 5개 |
| 2개 | 최대 3개 | 5개 |
| 3개 | 최대 2개 | 5개 |
| 4개 | 최대 1개 | 5개 |
| 5개 | 0개 | 5개 |

돌은 계속 추가되는 방식이 아닙니다.

매 라운드마다 자신의 **최종 배치 위치**를 다시 결정합니다.

유지하지 않는 돌은 거리 제한 없이 원하는 위치로 이동할 수 있습니다.

---

## 4. 전멸했을 경우

충돌로 자신의 돌이 모두 제거되어 생존 돌이 0개가 되면 다음 라운드는 **돌 3개로 다시 시작**합니다.

즉,

```text
생존 돌 있음
→ 기존 돌 최소 1개 유지
→ 총 5개 배치

생존 돌 0개
→ 돌 3개로 재시작

```


## 예고형 폭격 모드

새 경기부터 다음 규칙이 적용됩니다. 기존에 진행하던 경기는 종료 후 다시 시작할 때 적용됩니다.

| 라운드 | 폭격 |
|---|---|
| 1 | 없음 |
| 2, 4, 6… | 외곽 한 줄: 맨 위·아래 행 또는 맨 왼쪽·오른쪽 열 |
| 3, 5, 7… | 지점 50%, 가로줄 25%, 세로줄 25% |

외곽은 서버가 섞은 순서대로 선택합니다. 이전 폭격의 잿더미와 완전히 겹치는 대상은 피하며, 해당 외곽은 이후 차례로 미룹니다. 무작위 폭격은 종류를 먼저 정하고 사용 가능한 위치 중 하나를 고릅니다. 아직 공개하지 않은 외곽 순서는 클라이언트에 보내지 않습니다.

### 라운드 진행

1. 서버가 폭격 위치를 확정하고 모두에게 주황색 표시와 좌표로 예고합니다.
2. 15초 동안 비공개 배치합니다. 폭격 예정 위치도 선택할 수 있습니다.
3. 배치를 공개하고 같은 칸에 놓인 돌을 제거합니다.
4. 폭탄 낙하·폭발 연출과 함께 폭격 위치의 돌을 제거합니다.
5. 최종 생존 돌로 5목을 판정합니다. 여러 명이면 공동 우승입니다.
6. 승자가 없다면 다음 라운드를 시작합니다. 폭격 위치는 그 라운드 한 번 동안 잿더미가 되어 배치가 금지됩니다.

공개 연출은 기존 2초 공개 구간 안에서 약 1.4초간 재생합니다. 서버가 최종 결과를 확정하고 클라이언트는 공개 시각에 맞춰 연출합니다. 공개 전에는 다른 사람의 배치가 전달되지 않습니다. 움직임 줄이기 설정에서는 낙하·섬광 연출을 생략합니다.

고정한 돌도 폭발로 제거됩니다. 전멸하면 다음 라운드는 3개, 생존 돌이 있다면 기존 위치 최소 1개를 유지하며 총 5개를 선택합니다. 잿더미는 클라이언트와 서버 양쪽에서 배치를 차단합니다. 새 경기에서는 폭격·잿더미·공개 연출 상태를 초기화합니다.

이 규칙은 같은 구석 반복 사용을 어렵게 하지만 구석 승리를 금지하지는 않습니다. 인원별 보드 크기, 15초 제한, 최대 라운드 없음 규칙은 유지됩니다.

### 검증 명령

의존성 설치 후 게임 폴더에서 실행합니다(Node.js 22.13 이상).

```sh
node tests/bombs.mjs
node tests/rules.mjs
node tests/optimistic.mjs
node tests/board-size.mjs
```

폭격 순서·범위, 공동 우승, 전멸, 시간 초과, 잿더미 차단·해제, 공개 전 비밀 유지, 서버 예고 일치, 재경기 초기화와 기존 배치·보드 규칙을 확인합니다. 실제 사람 간 2·4·6인 밸런스 테스트는 별도로 진행해야 합니다.
