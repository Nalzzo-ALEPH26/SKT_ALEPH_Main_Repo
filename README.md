## 눈치오목 v2

> **생각은 몰래, 승부는 동시에.**

상대의 선택을 예상하며 자신의 돌을 비공개로 배치하고, 모든 플레이어의 선택을 동시에 공개하는 심리전 보드게임입니다.

같은 위치를 두 명 이상이 선택하면 해당 위치의 돌은 모두 제거되며, 충돌 처리 후 자신의 돌 5개를 가로·세로·대각선 중 한 방향으로 연결하면 승리합니다.

- **플레이 인원:** 2~6명
- **플랫폼:** PC 웹브라우저
- **핵심 요소:** 비공개 배치, 위치 예측, 충돌, 재배치
- **라운드 제한 시간:** 15초
- **게임 방식:** 방 코드 기반 온라인 멀티플레이

### 주요 규칙

- 첫 라운드에는 돌 3개를 배치합니다.
- 이후 라운드에는 최대 5개의 최종 위치를 결정합니다.
- 기존 생존 돌이 있다면 최소 1개는 기존 위치에 유지해야 합니다.
- 같은 위치에 여러 플레이어의 돌이 겹치면 모두 제거됩니다.
- 충돌 후 돌 5개가 일직선으로 연결되면 승리합니다.
- 같은 라운드에서 여러 명이 승리 조건을 만족하면 공동 우승입니다.
- 모든 돌이 제거된 플레이어는 다음 라운드에서 돌 3개로 다시 시작합니다.

## 연결의 한 수 Online

> **생각은 비밀로, 판정은 동시에.**

모든 플레이어가 매 턴 두 곳을 비밀리에 선택하고 투표권을 배분한 뒤, 제출이 끝나면 한꺼번에 판정하는 실시간 전략 보드게임입니다.

같은 위치를 여러 명이 선택하면 더 많은 투표권을 사용한 플레이어가 해당 교차점을 차지하며, 자신의 돌을 상·하·좌·우로 크게 연결할수록 점수와 다음 턴 투표권이 증가합니다.

- **플레이 인원:** 2~8명
- **플랫폼:** PC / 모바일 웹브라우저
- **장르:** 동시 선택형 전략 보드게임
- **핵심 요소:** 연결 확장, 상대 연결 방해, 투표권 배분, 동시 선택 심리전
- **게임 방식:** 방 코드 기반 온라인 멀티플레이
- **총 턴:** 5턴

### 주요 규칙

- 매 턴 서로 다른 두 교차점을 선택하고 투표권을 나누어 사용합니다.
- 같은 위치에서는 가장 많은 투표권을 사용한 플레이어가 해당 위치를 차지합니다.
- 최고 투표수가 동률이면 기존 상태를 유지합니다.
- 이미 돌이 놓인 위치도 다시 선택할 수 있습니다.
- 가장 큰 연결 묶음 크기만큼 점수와 다음 턴 투표권을 얻습니다.
- 5턴 종료 후 누적 점수가 가장 높은 플레이어가 승리합니다.
