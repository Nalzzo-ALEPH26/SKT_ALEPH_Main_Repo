## 눈치오목 v2

> **생각은 몰래, 승부는 동시에.**

상대의 선택을 예상하며 자신의 돌을 비공개로 배치하고, 모든 플레이어의 선택을 동시에 공개하는 심리전 보드게임입니다.

같은 위치를 두 명 이상이 선택하면 해당 위치의 돌은 모두 제거되며, 충돌과 폭격·폐쇄 처리 후 자신의 돌 **정확히 5개**를 가로·세로·대각선 중 한 방향으로 연결하면 승리합니다.

- **플레이 인원:** 2~6명
- **플랫폼:** PC 웹브라우저
- **핵심 요소:** 비공개 배치, 위치 예측, 충돌, 폭격, 외곽 폐쇄
- **선택 제한 시간:** 25초
- **게임 방식:** 방 코드 기반 온라인 멀티플레이

### 주요 규칙

- 첫 라운드에는 돌 3개를 배치합니다.
- 기존 생존 돌이 있는 라운드에는 총 6개의 최종 위치를 결정합니다.
- 기존 생존 돌이 2개 이상이면 최소 2개를 기존 위치에 유지합니다.
- 생존 돌이 1개뿐이면 해당 돌 1개를 유지합니다.
- 같은 위치에 여러 플레이어의 돌이 겹치면 모두 제거됩니다.
- 라운드에 따라 무작위 폭격 또는 외곽 한 줄 폐쇄가 발생합니다.
- 충돌과 폭격·폐쇄 처리 후 정확히 5개의 돌이 일직선으로 연결되면 승리합니다.
- 한 줄로 6개 이상 이어진 경우 해당 줄은 승리로 인정하지 않습니다.
- 같은 라운드에서 여러 명이 승리 조건을 만족하면 공동 우승입니다.
- 경기 종료 후 최근 경기를 다시 볼 수 있습니다.

## 연결의 한 수 Online

> **생각은 비밀로, 판정은 동시에.**

모든 플레이어가 매 턴 두 곳을 비밀리에 선택하고 투표권을 배분한 뒤, 제출이 끝나면 한꺼번에 판정하는 실시간 전략 보드게임입니다.

같은 위치를 여러 명이 선택하면 더 많은 투표권을 사용한 플레이어가 해당 교차점을 차지하며, 자신의 돌을 상·하·좌·우로 크게 연결할수록 점수와 다음 턴 투표권이 증가합니다.

- **플레이 인원:** 2~8명
- **플랫폼:** PC / 모바일 웹브라우저
- **장르:** 동시 선택형 전략 보드게임
- **핵심 요소:** 연결 확장, 상대 연결 방해, 투표권 배분, 동시 선택 심리전
- **게임 방식:** 방 코드 기반 온라인 멀티플레이
- **총 턴:** 5턴

### 주요 규칙

- 매 턴 서로 다른 두 교차점을 선택하고 투표권을 나누어 사용합니다.
- 같은 위치에서는 가장 많은 투표권을 사용한 플레이어가 해당 위치를 차지합니다.
- 최고 투표수가 동률이면 기존 상태를 유지합니다.
- 이미 돌이 놓인 위치도 다시 선택할 수 있습니다.
- 가장 큰 연결 묶음 크기만큼 점수와 다음 턴 투표권을 얻습니다.
- 5턴 종료 후 누적 점수가 가장 높은 플레이어가 승리합니다.

## 힌트 오목 (Hint Omok)

> **힌트는 둘, 진실은 하나.**

이전 플레이어가 남긴 **두 개의 힌트 중 진짜 정보를 추리하며 진행하는 최대 4인 실시간 멀티 오목**입니다.

일반 오목의 수 싸움에 불완전한 정보를 이용한 추리 요소를 더했습니다. 플레이어는 현재 보드뿐만 아니라 전달받은 힌트를 함께 확인하면서 다음 수를 결정해야 합니다.

- **플레이 인원:** 최대 4명
- **플랫폼:** 웹브라우저
- **장르:** 추리형 멀티플레이 보드게임
- **핵심 요소:** 오목, 힌트, 추리, 정보 판단
- **게임 방식:** 방 코드 기반 온라인 멀티플레이
- **실시간 동기화:** Firebase

### 주요 규칙

- 플레이어는 자신의 차례에 오목판의 위치를 선택합니다.
- 선택이 끝나면 다음 플레이어에게 이전 선택과 관련된 두 개의 힌트가 전달됩니다.
- 두 힌트 중 하나는 진짜이고 하나는 가짜입니다.
- 다음 플레이어는 현재 보드와 힌트를 바탕으로 진짜 정보를 추리합니다.
- 플레이어는 추리한 정보를 참고하여 자신의 다음 수를 결정합니다.
- 가로·세로·대각선으로 오목을 완성하면 승리합니다.
